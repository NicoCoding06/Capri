# Capri

Sito personale: pagina Oggi, ticket con urgenze e allegati, wishlist con prezzi Magic automatici
(Scryfall/Cardmarket), finanze (spese, abbonamenti e scadenze, fogli in stile Excel), note e
notifiche giornaliere su iPhone.

- Pubblicato con GitHub Pages da questo repository.
- Dati e allegati su Supabase, visibili solo dopo il login (vedi `setup.sql`).
- Per modificare il sito: vedi `CLAUDE.md`.
