# Capri

Sito personale: ticket, wishlist con prezzi Magic automatici (Scryfall/Cardmarket) e finanze in stile Excel.

- Pubblicato con GitHub Pages da questo repository (cartella principale, ramo `main`).
- Dati e allegati su Supabase: il collegamento è in `config.js` (URL del progetto e chiave anon/publishable, pensate per stare nel sito).
- La configurazione del database è in `setup.sql`, da eseguire una volta nel SQL Editor di Supabase.
- I dati sono visibili solo dopo il login e le regole del database permettono a ogni utente di vedere solo i propri.
